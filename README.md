# Personal Expense Tracker 💰

A Python-based command-line application for managing personal finances.

## Features

- Create and manage financial accounts
- Track income and expenses
- Organize transactions by category
- Set monthly budgets and monitor spending
- Generate monthly financial reports
- Transfer money between accounts
- Track debts and payments
- Create and manage savings goals
- Store data locally using SQLite

## Technologies

- Python
- SQLite
- SQL
- Git & GitHub

## Getting Started

### Requirements

- Python 3.10 or later

### Run the application

1. Clone this repository.
2. Open a terminal in the project directory.
3. Run:

```bash
python expense_tracker.py
```

The SQLite database will be created automatically when the application starts.
